## 核心设计与交互范式

1. **AI 科技工业杂志美学**  
   黑曜石底色、暖骨白正文、青铜索引与发丝线分隔。拒绝泛滥的模板化霓虹发光与圆角玻璃卡片，还原硬核制造实业与前沿智能结合的理性高级质感。
2. **三项关键指标 × 场景收益对账**  
   直截了当呈现核心产出：秒级动态排产（`5s` / 稼动率 `+28%`）、全天候数字销冠（`7×24h` / 转化率 `+300%`）、旧系统零推倒（`0中断` / `100%` 资产保护）。
3. **真实一天叙事对比**  
   提供实业老板老张与超级个体小李的 24 小时真实工作流对比，支持双视角实时切换与完整实录展开。
4. **原位 Toggle 隐现机制 (Inline Toggle Show/Hide)**  
   主干保持利落克制，深入细节（技术规格、案例复盘、历史纪元、联络终端）点击后在当前文档流内原地平滑展开与收起，视线无需跳跃，杜绝弹窗抽屉打断沉浸阅读与破坏页面滚动。
5. **轻量纯粹、零构建负担**  
   不引入沉重的庞大前端框架，原生现代 HTML5 / CSS3 / ES Modules 编写，无打包编译步骤，首屏秒级直出。

## 快速上手与本地调试

### 1. 本地启动服务

推荐使用任意本地静态 HTTP 服务器运行：

```bash
# 使用 Python 启动
python3 -m http.server 4321

# 或使用 npx serve
npx serve -l 4321 .
```

浏览器访问 `http://localhost:4321/` 即可进入门户导航；亦可分别直达：
- 品牌主刊：`http://localhost:4321/nexus-ai-website/`
- 业务副刊：`http://localhost:4321/nexus-ai-services-website/`

### 2. 自动化验收测试

仓库内置 270 项无头 JSDOM 自动化验收测试，覆盖代码行数硬红线、状态机契约、头尾通栏规范、移动端导航互斥、英文版全要素、无障碍 ARIA、深链、交互与反模式清零：

```bash
# 运行完整测试套件
npm test
```

## 部署规范

本项目已配置支持 **GitHub Pages** 静态自动化部署：
- 根目录包含 `.nojekyll`，禁用 Jekyll 构建以完整保留静态资产与目录结构。
- 推送至 `main` 分支后，GitHub Pages 即可自动完成静态发布。
